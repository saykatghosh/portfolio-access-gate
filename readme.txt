Protect WordPress pages with business email verification and capture high-quality business leads.

== Description ==

Portfolio Access Gate helps agencies, freelancers, and businesses protect selected WordPress pages while collecting verified business leads.

Features include:

* Dashboard Analytics
* Protected Pages
* Business Email Verification
* Lead Capture
* Lead Management
* Search Leads
* View Lead Details
* Delete Leads
* CSV Export
* Responsive Admin Dashboard

== Installation ==

1. Upload the plugin ZIP.
2. Activate the plugin.
3. Go to Portfolio Access Gate.
4. Select the pages you want to protect.
5. Save changes.
